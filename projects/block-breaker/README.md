# ブロック崩し

## 作品概要

C++とDxLibで制作したWindows向けブロック崩しゲームです。バーを操作してボールを反射させ、16列×3行のブロックをすべて破壊するとクリアになります。ボールの移動、当たり判定、反射、描画、ゲーム状態をそれぞれ関数へ分割しています。

## 使用技術

- **C++17**: ゲームループ、構造体、列挙型、状態管理
- **DxLib**: ウィンドウ生成、キー入力、2D描画、ダブルバッファリング
- **Visual Studio 2022**: C++プロジェクトの開発とビルド
- **MSBuild**: x86・x64、Debug・Release構成の管理
- **Windows**: 実行対象プラットフォーム

## 操作

- `A` / `←`: バーを左へ移動
- `D` / `→`: バーを右へ移動
- `Space`: クリア・ゲームオーバー後に再開
- `Esc`: 終了

## 実装内容

- 16列×3行のブロック配置
- 円と矩形の最近接点を使った当たり判定
- バーの接触位置に応じた反射方向の変化
- クリア、ゲームオーバー、再開の状態管理
- ダブルバッファリングによる描画

## ビルド方法

1. Visual Studio 2022とDxLibを用意します。
2. DxLibの「プロジェクトに追加すべきファイル_VC用」ディレクトリを、環境変数 `DXLIB_DIR` に設定します。
3. `block-game.sln` を開き、x64またはx86でビルドします。

例（PowerShell）:

```powershell
$env:DXLIB_DIR = "C:\path\to\DxLib_VC\プロジェクトに追加すべきファイル_VC用"
```

環境変数を永続化した場合は、Visual Studioを再起動してからビルドしてください。
