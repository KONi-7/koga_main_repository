# 一夜漬け徹底攻略サイト

## 作品概要

HTML・CSS・JavaScriptの基礎学習として制作した、日英切替対応の複数ページWebサイトです。グローバルナビゲーション、固定サイドメニュー、言語切替、レスポンシブ表示、チャット風UIを実装しています。

## 使用技術

- **HTML5**: ヘッダー、ナビゲーション、本文、フッターの文書構造
- **CSS3**: 配色、余白、文字、ホバー・フォーカス表示
- **CSS Grid / Flexbox**: サイドメニュー、本文、商品紹介のレイアウト
- **Media Queries**: PC・スマートフォン向けの表示切替
- **JavaScript**: DOM操作、クリック・EnterキーによるチャットUI
- **Web Accessibility**: `alt`、`aria-label`、フォームラベル、キーボード操作
- **Multilingual Pages**: 日本語・英語ページの切替

## 主な実装

- 日本語5ページ、英語5ページ
- グローバルナビゲーションとサイドナビゲーション
- 現在のページを示す表示
- セレクトボックスによる言語切替
- レスポンシブレイアウト
- JavaScriptによるチャットUIデモ

## 閲覧方法

`index.html` をブラウザで開いてください。ローカルサーバーを利用する場合は、このディレクトリで次を実行します。

```bash
python -m http.server 8000
```
