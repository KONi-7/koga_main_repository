Overnight Study Guide

This is an HTML, CSS and JavaScript learning project. It does not recommend sleep deprivation or excessive caffeine intake.

This bilingual website was created as an exercise in building a multi-page site with HTML, CSS and JavaScript.

It explores study planning through the theme of last-minute revision while demonstrating navigation, language switching, responsive layout and a small chat interface.

For real study, plan ahead where possible and prioritise sufficient sleep.
